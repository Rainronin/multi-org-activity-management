## 已踩坑（新 AI 必读）

| 坑 | 正确做法 |
| --- | --- |
| Hikari 隔离级别须用 JDBC 常量名 | `transaction-isolation: TRANSACTION_READ_COMMITTED`（非 `READ_COMMITTED`） |
| 登录成功轮换 CSRF token | 前端 session 层在登录/退出后作废缓存并重取 |
| headless Chrome 的 --window-size 受 Windows 125% DPI 影响 | 判断溢出须用 CDP `Emulation.setDeviceMetricsOverride` + `scrollWidth == clientWidth` |
| 长内联 shell 脚本会被截断 | 大文件一律用 Write 工具；补丁脚本写文件后执行 |
| Windows curl 中文 JSON 以 GBK 发送致 400 | 用 UTF-8 临时文件作请求体 |
| `Path.of("./uploads")` 的 startsWith 不含 `"."` 前缀元素 | 必须 `toAbsolutePath().normalize()` 后再比较 |
| 显式导入 Element Plus 时 v-loading 和 ElTableColumn 需注意 | v-loading 需本地注册 `const vLoading = ElLoading.directive`；组件必须显式导入 |
| record 组件访问须用方法调用 | `item.description()` 而非 `item.description` |
| Spring Security 登录成功轮换 CSRF token | 后续写操作须用新 token；MockMvc 测试用 `with(csrf())` 不受影响 |

## 关键设计决策（新 AI 易犯错的点）

1. **活动可见性**：草稿/待确认仅 OWNER 与活动负责人；已确认对全部有效成员可见（`canSeeDraft` 统一入口）。
2. **成员主关系复用**：重新加入复用原行（memberId 稳定）；被移除者仅凭移除后新邀请加入。
3. **退出责任检查**：退出/移除前检查未结任务与物资，409 `MEMBER_HAS_OPEN_DUTIES`；改派后可退出。
4. **组织行锁**：所有组织业务写入先取组织行共享/排他锁，锁内重读当前状态并重验身份。
5. **S04 修复**：审核权限 = 组织负责人**或**活动负责人（requireReviewPermission）。
6. **S05 修复**：advanceOwn 仅允许 PENDING→IN_PROGRESS→COMPLETED，非法流转返回 409（非 403）。
