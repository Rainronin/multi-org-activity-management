## 一、使用与完成规则

1. 小阶段以 `P阶段.序号` 标识，例如 `P4.2 报名审核与名额`，可以直接作为一次开发任务的范围。
2. 勾选功能项表示相关页面、接口、持久化、权限及必要异常处理均完成并验证；仅完成静态页面或模拟接口不能勾选。纯工程或文档项按其描述验收。
3. 每个小阶段先落实必要的页面、字段和接口约定，再实现一条可操作的前后端流程，不先堆完所有页面再集中补后端。
4. 权限、数据归属、状态校验、防重复和审计跟随对应功能开发；最后的综合验收用于复核，不是首次补安全和业务规则。
5. 大阶段表示依赖顺序，不强制一次写完整个阶段。后续业务产生的成员退出、活动取消等联动，须回到对应小阶段补齐后才能认定完成。
6. 每个小阶段完成时，在相关测试记录中留下使用的账号身份、操作、预期与实际结果；关键反例保留可重复执行的检查。无需给每条静态文案机械编写测试。
7. 下列任务均属本期范围；“后做”不等于“选做”。动效库、可选成员分组等不属于必做业务的验收前提。

8. P1.4 的基础授权先完成，成员退出的跨业务联动随 P3—P6 补齐，不能因此阻塞 P2，也不能提前勾选联动项。P0.2 按已确认的 UI 规范落实 token、主题与检查规则；布局及授权联动随首个实际页面落地，未实现部分保留未勾选，但不阻塞 P1。

### P7 工作台与站内提示（M09、M10）

阶段完成条件：从真实业务记录展示不同身份的待办与指标，提示可追溯且不泄露撤权后的数据。

#### P7.1 分身份工作台与本人待办

- [ ] 组织负责人查看组织范围内待确认事项和活动概览；活动负责人聚焦本人负责活动。
- [ ] 普通成员查看本人任务、报名与提示；外部参与者通过公开活动及本人报名入口使用系统。
- [ ] “我的待办”只列本人尚未处理的任务或确认事项，已完成默认排除，其他成员任务放管理视图。
- [ ] 待办可跳转对应详情，重新校验权限和当前状态，过期事项不继续显示可操作按钮。

#### P7.2 基础统计与明细追溯

- [ ] 实现进行中活动数：仅筹备中与执行中，复盘待办单独列出，取消归档不混入正常完成。
- [ ] 实现待处理任务、逾期任务和任务完成率；完成率以未取消任务为分母，分母为零显示“—”。
- [ ] 实现有效报名人数与名额使用率，取消活动展示历史结果，不显示正常招募进度。
- [ ] 汇总反馈份数、平均评分及活动经费指标，保持与 P5.3、P6.3 相同口径和权限范围。
- [ ] 每个数字说明时间范围和来源，并能进入授权明细复算；禁止固定演示数字、虚构增长趋势和无来源评分。

#### P7.3 站内提示与失败处理

- [ ] 接入任务分派、报名处理、活动审批、费用审批、关键变更和活动取消的必要提示，记录接收账号及来源操作。
- [ ] 实现必要的提示列表和详情跳转；截止临近与逾期按待办时间计算，无需定时群发。
- [ ] 提示只保留必要摘要，列表及目标详情都重新校验权限；撤权后不能通过旧消息获得内部信息。
- [ ] 主业务同事务保存必要提示意图；提交后投递失败不回滚业务，按固定接收人核对补建，进程中断和重复投递不漏发或重复产生有效提示。

### P8 AI 文本辅助（M11、M12）

阶段完成条件：两项功能均能真实调用模型、编辑和确认，失败时可继续手工完成方案与总结。

#### P8.1 共用调用与草稿保护

- [ ] 在组织设置提供 AI 模型配置，负责人可设置兼容协议、完整 API 端点、模型 ID、密钥及调用参数；两项生成共用，每组织一套当前配置。
- [ ] 实现 OpenAI Chat Completions 与 Anthropic Messages 两种必要适配，统一最终文本与错误，不按厂商品牌复制业务模块。
- [ ] 实现保存、测试、启用、停用、替换／清除密钥；配置变更使旧测试失效，地址或协议变化必须重输密钥，旧测试响应不得启用新配置。
- [ ] 实现密钥加密存储与不回显、脱敏审计、组织配置隔离及外部地址限制；主密钥由部署环境保管，浏览器不直连模型。
- [ ] 使用固定短文本测试已保存配置，提示可能消耗额度；测试与生成都限制频率、并发、响应体与时限，并处理在途配置变更。
- [ ] 调用前验证组织、活动、职责、状态及配置可用性；未配置或停用时保留人工编写路径。
- [ ] 只发送本次生成必需信息，排除联系方式、凭据和无关资料；输入中的诱导指令不能改变权限或触发操作。
- [ ] 限制输入量、调用频率、并发和等待时间；记录请求标识，重复点击不无限调用，结果不明不盲目重试。
- [ ] 记录类型、活动、操作者、模型、生成时间、输入范围或来源版本、输出及人工确认状态；普通日志不重复保存敏感原文。
- [ ] 展示生成中、失败、成功和可编辑新草稿；新结果与人工内容分开，未经替换确认不得覆盖。
- [ ] 模型文本安全显示，不执行 HTML、脚本或业务指令；生成返回及人工确认时再次核对权限和活动状态。
- [ ] 复用 AiDraftPanel 只处理生成与采用草稿，方案和总结分别由所属页面／服务保存；同一防重键重放也重新鉴权，不能返回撤权前的私有结果。

#### P8.2 AI 活动总结（M11）

- [ ] 在复盘页提供生成入口，允许用户预览本次输入范围及缺失信息。
- [ ] 从当前活动授权记录提取目标、已确认方案、任务、执行、报名、已确认费用及反馈；程序计算人数、金额和比例。
- [ ] 生成目标与执行概况、成果、反馈要点、问题及改进建议，事实与建议分开，不生成未记录的到场或成果结论。
- [ ] 支持编辑、保存草稿、确认总结；来源变化后提示复核或重新生成，不能自动覆盖人工内容。

#### P8.3 AI 方案生成（M12）

- [ ] 在活动草稿方案编辑区提供入口，输入主题、目标、对象、人数、预算、时间地点条件及补充限制。
- [ ] 生成方案概述、流程、分工、物资与费用建议、注意事项和备选安排；缺失条件标注假设或待补充项。
- [ ] 说明建议费用是估算，不冒充报价、批准预算或已确定场地；不自动创建任务、物资及支出记录。
- [ ] 支持生成、人工编辑及确认保存方案；保存不等于立项通过，仍走 P2.2 的提交确认流程。

#### P8.4 两项 AI 功能的验收样本

- [ ] 分别完成至少一次真实总结生成、真实方案生成及人工修改确认；两种兼容协议分别验证真实文本调用，保留不含密钥的必要证据。
- [ ] 覆盖正常、资料不足、相互矛盾、敏感信息、诱导文字、模型超时、额度不足和无效输出。
- [ ] 模型故障保留原内容，可继续手工编写；不以固定模板、预置文本或字数冒充真实生成成功。
- [ ] 验证生成期间源数据变化、权限撤销、组织切换、模型配置变更／停用和活动归档时，草稿不会越权展示或写入；测试恶意地址、密钥不回显及上游 401 不触发本站退出。

## 六、明确不进入本期清单的内容

- 签到、扫码、定位、核验凭证、到场率与出勤评价。
- OCR、票据自动识别、多模态识图、AI 自动审批或执行业务、预测和自训练模型。
- 在线支付、完整报销结算、组织资金账户、库存借还和资产管理。
- 即时聊天、短信或邮件业务通知、原生移动应用、离线同步。
- 多级组织树、通用角色编辑器、可配置审批、任务依赖、子任务树和工时系统。
- 通用问卷、跨活动整改系统、独立知识库、文件版本库、语义检索与跨实体全局搜索。
- 综合健康评分、成员排行榜、性别统计及无数据来源的趋势图。

成员扁平分组为可选归类，GSAP／Vue Bits 为可选视觉实现，不作为本期完成前提。增加范围外功能时，先明确需求并同步计划书与本清单，不能仅因 AI 生成了额外代码就纳入项目。
