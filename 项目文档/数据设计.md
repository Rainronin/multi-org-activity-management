# 数据设计

> 本文按当前迁移、持久化记录与服务约束维护实际字段合同；业务端点由[接口说明](接口说明.md)维护。概念 ER 图不对应物理表数量，文档同步不代表业务、部署或恢复已整体验收；当前审核结论见[开发进度审核报告](开发进度审核报告.md)。

用途：按开发规范第五节，在首个相关模块迁移前记录字段、约束、索引与保留规则；按模块逐段增量维护。已落地结构以 [backend 迁移](../基于Vue3的多组织活动管理系统_zcode/backend/src/main/resources/db/migration)为准并同步说明。概念 ER 图不作为物理表依据。

通用约定：

- 表与列名 snake_case；标识内部为 BIGINT UNSIGNED，接口层一律以字符串传输（开发规范 2.2）。
- 时间点统一 UTC（连接时区 UTC），列类型 TIMESTAMP(6)；纯日期（费用发生日期等）使用 DATE。
- 金额表在对应模块建表时以 DECIMAL(12,2) 起步（人民币），容量在该模块迁移前定稿。
- 状态枚举以 VARCHAR 存储、UPPER_SNAKE_CASE；不使用 MySQL ENUM，便于迁移扩展。
- 已应用迁移不回写；演示重置仅针对独立测试库。

当前物理结构以V1—V27迁移为准，开发库正常启动与独立测试库均已升级V27。所有自动化写验证仅用activity_test；标识在Controller输出时转换为字符串，库内BIGINT不变。验证结果与范围见审核报告，原阶段过程见开发日志。

成员退出／移除的内部报名联动同时检查实际生命周期：未来计划开始时间不能将已处于 `EXECUTING/REVIEWING/ARCHIVED` 的活动当作未执行而取消报名；未进入执行的内部待审／有效报名按既有规则取消，公开报名保留。三类职责在锁内检查，已完成任务、已就绪物资及归档历史不通过删行解除责任。

已作废费用才能建立关联更正登记；未作废、草稿、待确认及已驳回原记录不能创建更正，原键重放仍沿用现有唯一约束。普通附件的同键重放再次检查原操作者、活动／任务／费用及文件内容，保持已有指纹算法及历史请求兼容。

**当前正文与确认历史：** activity继续保存最新草稿及当前确认字段；V24 activity_confirmation只在确认时独立追加正文，后续保存／重开不覆盖历史。旧确认审计只有sourceHash，迁移不从现正文伪造历史；audit_log仍不代替正文快照。旧记录可能没有历史，新确认开始保存；本轮关键操作前后状态与requestId增量见下方，历史不回填。

**概念文稿、AI 与附件映射：** 图中活动文稿以活动及类型标识，涵盖方案、总结与取消说明；当前正文分别保存为 activity.proposal 和 activity.summary，确认历史为 activity_confirmation，不存在独立 document 表、文稿编号或作者成员外键。AI 生成按活动及类型保留记录，连接测试的 activity_id 为空；adopted_at／adopted_by 仅记录人工采用，不代表业务正文已保存，也不是最终正文的精确生成来源。attachment 只支持 ACTIVITY_DOC、TASK_ATTACHMENT、EXPENSE_VOUCHER，任务与费用关联互斥；方案／总结相关文件作为活动资料管理，没有文稿附件外键。概念人员联系表达业务权限或历史操作；下方只将迁移实际声明的约束标为 FK。

### V24 活动确认快照（2026-10-04持续批已验证）

`activity_confirmation`：自增BIGINT UNSIGNED id，activity_id外键，kind VARCHAR(16)检查约束PROPOSAL／SUMMARY／CANCEL_NOTE，MEDIUMTEXT content，BIGINT activity_version、CHAR(64) source_hash、confirmed_by账号外键、TIMESTAMP(6) confirmed_at、可空VARCHAR(500) reopen_reason及INT reopen_count。其余列非空，唯一键(activity_id,activity_version)兼顾防重与按版本读取索引；无额外org_id，先授权活动再读取。既有确认事务在更新当前确认字段后追加同版本／时间快照，没有更新／删除接口，普通编辑／重开只改activity当前字段。方案摘要为正文SHA-256，总结与取消说明使用来源摘要；当前权限复用活动可见性，不新增历史访问范围。真实SELF／OTHER确认、正常／取消更正、旧正文不变、授权读取与退出404均通过。

归档重开清当前summary_confirmed_at／by／source_hash，保留历史快照、原取消时间与更正记录；cancelled_at存在时回CANCELLED，否则REVIEWING。来源摘要覆盖任务／物资／费用版本和完整反馈正文，不截前1000份报名；算法变更不回写旧摘要，旧确认来源可能需人工再次确认。summaryNeedsReview为查询时派生字段，不新增列或自动写入。

物资正常归档的处置例外复用material.assignee_member_id及note，并在现有组织锁内核对承担者同组织、ACTIVE；历史已退出／移除关系仍保留署名，不能充当未结束物资的当前处置人。READY／CANCELLED保持原结束含义，无新表、状态或自动完成写入，取消归档仍人工核对遗留说明。

2026-10-04追加防重范围修复只使用现有activity.created_by、expense.created_by／activity_id校验原意图；两个组织＋request_key唯一约束、旧request_fingerprint算法和历史内容均不变，不通过重写历史摘要消除歧义。跨账号／费用跨活动同键拒绝；当前权限继续先核，正常旧键核对返回原记录，当前全范围验收结论见审核报告。

费用登记／更正的既有原键在活动转只读后允许授权核对已有记录，不新增expense或创建审计；仅调整Service守卫顺序，没有表／约束／指纹修改。真实activity_test中ARCHIVED／PENDING_APPROVAL各2场景返回原id，新键仍被拒绝，普通登记计数1、更正含原作废记录计数2；历史数据不回写。

更正同键并发继续由uk_expense_org_request_key保证只1份新记录，Service将唯一冲突500改为409 REQUEST_IN_PROGRESS，失败事务回滚、原键可核对；普通／更正8路真实API均核记录和创建审计只1份。无新增约束／隔离级别／锁模式改变，仍V24。

### V25 活动／费用创建指纹格式（已验证）

两表request_fingerprint由CHAR(64)扩为VARCHAR(67) NULL，新写入v2:＋64位字段长度编码摘要；NULL字段按-1长度、文字按实际长度，区分字面量"null"及分隔符。仅已有64位值使用原算法，NULL摘要仍不能核对；原账号、活动及更正原记录检查和组织＋键唯一约束不变，创建后编辑仍不改指纹。无历史重算／回填，旧摘要固有歧义不能恢复；本轮仅允许无歧义的旧字符串输入核对，歧义匹配409 IDEMPOTENCY_RESULT_UNVERIFIABLE并要求人工核列表，既有值不变；迁移前后各10条旧值抽样不变、两条真实编辑后旧键兼容通过，非全库逐行验证。新格式只用于这两表，其他表已有指纹列不改变。

迁移显式COPY／SHARED、无并发写入承诺；发布维护和禁止缩列截断新值的回退限制见[部署说明](部署与恢复说明.md)。

### V27与关键审计增量（2026-10-05）

V27为registration／feedback各追加BIGINT NOT NULL DEFAULT 1的version，显式ALGORITHM=INSTANT，旧行初始化1，不改状态／正文。报名再申请、审核、取消按原版本条件更新并递增，活动取消／离组亦递增；首次可缺省或0，后续缺版本400／旧版本409。反馈首次可缺省或0，修改必带原版本，两份同版本修改只有一份成功；myVersion无记录时0。独立写验证仅activity_test；开发库在用户授权的正常启动时已升级V27，未做V27整库恢复演练。

其余不新增表／列。AuditService.recordChange复用原detail追加before／after，白名单含锁内实际状态、版本、关系／归属、金额或必要计数。账号含authVersion／当前恢复凭据id；成员含关系状态／角色；邀请含有效期／次数／状态；费用含状态／版本／金额／决定人／更正原id；附件含用途／关联／大小／deleted；报名、反馈、资格含状态／版本或rating／source；AI配置含连接／测试修订、启用／hasApiKey，生成含状态／类型／采用／错误码。活动／任务／物资已有快照继续复用，批量取消与离组逐对象审计；资格INSERT IGNORE只有实际新增行审计，actor为实际操作者。访问导出及文件清理失败不伪造业务快照；request_id取服务端MDC，旧行／非HTTP可NULL。秘密和正文不入审计，失败同事务回滚，不回填历史。

连接测试复用ai_generation.CONNECTION_TEST及可空activity_id、原账号／组织／请求键与原配置版本指纹，沿既有唯一约束防重。UNKNOWN为已有传输不明FAILED的响应映射，不新增库状态；原键GET不调用模型，上游超时／中断不代表厂商未处理。附件GET查原登记，不新增列或复活删除记录。

## 账号模块（M01，P1.1）

V26为audit_log追加可空VARCHAR(64) request_id，显式ALGORITHM=INSTANT，不改历史、detail结构或索引。公共AuditService从服务端MDC读取，非HTTP和旧记录NULL；原键核对不增加历史或改变首次标识。requestId只关联单次请求，不能作为防重键；关键前后状态合同见下方各模块与V27增量，恢复验收限制见部署说明。

### account 账号（全局登录身份）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK AUTO_INCREMENT | 内部主键 |
| username | VARCHAR(32) | NOT NULL，UNIQUE（utf8mb4_0900_ai_ci，大小写不敏感唯一） | 格式校验 `^[a-zA-Z0-9_]{3,32}$` |
| password_hash | VARCHAR(255) | NOT NULL | BCrypt 散列；不存明文，不进日志 |

保留规则：账号不物理删除（历史署名、审计与报名记录需要）；注销能力首期不建设。

2026-10-04任务／物资服务增量（仍V26，无表变更）：各3处审计入口保留原title／name或from／to明细，追加orgId、activityId、before／after。任务状态对象为status、version、assigneeMemberId、priority、completed（完成时间是否存在）；物资为status、version、assigneeMemberId（允许JSON NULL）、quantity、unit。创建before为JSON NULL，其余取子记录锁内旧行和实际更新行，正文description／note不复制。原请求键重放、旧版本拒绝、排队后权限／同状态拒绝不增审计；审计异常回滚创建／改派及任务分派通知。无旧detail回填、索引或业务表迁移；该段为当时6处入口的局部证据；本轮其他模块及批量联动增量见前文。

## 组织模块（M01，P1.2 起）

### organization 组织

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK AUTO_INCREMENT | |
| name | VARCHAR(64) | NOT NULL | 1～64 字符，创建时 trim；不强制全局唯一（同一系统可有同名组织） |
| description | VARCHAR(512) | NULL | 组织简介，可空 |
| status | VARCHAR(16) | NOT NULL DEFAULT 'ACTIVE' | 首期仅 ACTIVE；预留 DISABLED |
| created_by | BIGINT UNSIGNED | NULL，FK→account | V22；新建记录填写创建账号，历史记录保留 NULL |
| request_key | VARCHAR(64) | NULL | V22；组织创建的可选防重键 |
| request_fingerprint | CHAR(64) | NULL | V22；创建名称及简介的内容指纹 |
| created_at / updated_at | TIMESTAMP(6) | 同账号表约定 | |

索引：主键及 V22 的 `uk_organization_creator_request_key (created_by, request_key)`；组织名不唯一。可空键允许历史记录及旧无键调用兼容，新建同键由约束防重，创建者关系及审计同事务只写一次。重放重新检查原创建者当前成员身份，返回当前角色及原加入时间；不同创建账号的相同键独立。
保留规则：组织不物理删除；解散能力首期不建设。

### organization_member 组织成员关系

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK AUTO_INCREMENT | |
| org_id | BIGINT UNSIGNED | NOT NULL，FK→organization(id) | |
| account_id | BIGINT UNSIGNED | NOT NULL，FK→account(id) | |
| role | VARCHAR(16) | NOT NULL | OWNER（组织负责人）/ MEMBER（普通成员）；不建设通用角色编辑器 |
| status | VARCHAR(16) | NOT NULL DEFAULT 'ACTIVE' | ACTIVE / LEFT / REMOVED；LEFT／REMOVED 为历史状态，重新加入复用主关系行 |
| active_flag | TINYINT UNSIGNED | GENERATED ALWAYS AS (...) STORED | status='ACTIVE' 时为 1，否则 NULL；只由数据库生成 |
| joined_at | TIMESTAMP(6) | NOT NULL DEFAULT CURRENT_TIMESTAMP(6) | 首次加入时间 |
| created_at / updated_at | TIMESTAMP(6) | 同账号表约定 | updated_at 兼作被移除时间的判定基准 |

索引与约束：
- `uk_member_active (org_id, account_id, active_flag)`，其中 `active_flag` 为生成列（status='ACTIVE' 时为 1，否则 NULL）——同一账号在同一组织至多一条有效成员关系（计划书第九节）。
- `idx_member_account (account_id, status)`——本人组织目录查询。

**主关系复用模型（审核 R05 已修复）：** 退出（LEFT）或移除（REMOVED）不产生新行，而是将原行置为相应状态；凭有效邀请重新加入时**更新原行**为 ACTIVE／MEMBER，`memberId` 全生命周期稳定，可作为后续活动职责、任务与历史署名的外键基线。历史过程（加入、退出、移除、重新加入）以 audit_log 记录。被移除成员只能凭**移除之后创建**的邀请重新加入（以邀请 `created_at` 晚于成员行 `updated_at` 判定），移除前发出的邀请对其失效；自行退出成员可凭任何有效邀请重新加入。V5 迁移已把历史重复行收敛为单条主关系。

并发与锁（后端架构 5.1，审核 R01/R04 已修复）：组织首次创建为 INSERT，无既有组织行可锁；V22 同键重放取原组织共享锁并重读当前成员身份。成员与负责人变更、退出、移除、邀请接受与创建／撤销均取组织行排他锁（`SELECT ... FOR UPDATE`），**锁内重读当前状态并重验身份**；连接隔离级别统一 READ COMMITTED（Hikari `transaction-isolation`），并有真实 MySQL 并发测试覆盖（同账号重复接受、不同账号争抢末次、并发撤销负责人、撤权与创建竞争及同键创建）。当前职责联动的唯一编排入口为 OrganizationMemberService，与[后端架构](后端架构与技术栈设计.md)一致，不新增同义服务或重复事务入口。

### organization_invitation 组织邀请

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |

## AI 文本辅助（M11、M12，P8 起，V19）

### ai_config 组织模型配置（每组织一条）

| 列 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED | PK AUTO_INCREMENT | |
| org_id | BIGINT UNSIGNED | NOT NULL，FK→organization | 唯一键 `uk_ai_config_org`：每组织一套当前配置 |
| protocol | VARCHAR(32) | NOT NULL | `OPENAI_CHAT_COMPLETIONS`／`ANTHROPIC_MESSAGES` |

| api_key_cipher | VARBINARY(1024) | NULL | AES-GCM 密文（nonce ‖ 密文与认证标签），组织 ID 作为关联数据 |

| enabled | TINYINT(1) | NOT NULL DEFAULT 0 | 是否启用；配置修订变化时置 0 |
| connection_revision | INT | NOT NULL DEFAULT 0 | **连接修订**：协议、端点、模型、认证、密钥与调用参数变化时递增 |
| tested_revision / tested_at / tested_by | INT／TIMESTAMP(6)／BIGINT UNSIGNED | NULL | 最近一次成功测试绑定的修订、时间与测试人 |
| operator_account_id | BIGINT UNSIGNED | NOT NULL | 最近操作账号（脱敏审计用，不存密钥） |
