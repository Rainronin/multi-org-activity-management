# 多组织活动管理系统

一个面向社团、团队与组织的活动协作平台。以组织为协作边界，将活动策划、任务分工、报名、经费与执行复盘连接起来，让活动从想法到归档都有清晰的记录。

## 项目特色

- **多组织协作**：一个账号可加入多个组织，在独立工作区中管理活动与成员。
- **完整活动流程**：从草稿与方案、立项审批，到筹备执行、总结确认与归档，按阶段组织工作。
- **明确分工**：任务、物资和活动资料集中管理，支持负责人分配、状态跟进与文件查看。
- **灵活报名**：支持组织内部与公开活动报名，提供审核、名额控制及参与记录。
- **经费管理**：记录活动预算、收入与支出，查看明细及统计。
- **AI 文稿辅助**：结合活动信息生成方案或总结草稿，支持人工审阅、修改与保存；组织可配置兼容的模型服务。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 账号与个人工作区 | 注册登录、账号恢复、组织入口、我的报名、站内提示 |
| 组织管理 | 创建与加入组织、邀请、成员与组织设置 |
| 活动管理 | 活动方案、审批、阶段推进、报名安排与归档 |
| 协作执行 | 任务分派、物资准备、资料上传、执行记录 |
| 经费与复盘 | 收支记录、经费统计、参与反馈、活动总结 |
| AI 辅助 | 组织模型配置、方案与总结生成、草稿采用 |

## 界面与体验

系统采用可折叠侧栏与分区工作台，提供桌面和窄屏布局。活动详情按方案、任务与物资、报名、经费、执行与复盘组织内容，正文编辑与 AI 辅助各有清晰区域。

动效用于状态反馈、数字变化与登录页品牌背景，支持减少动态效果偏好；背景动画可暂停，在不适用或加载失败时回退为静态展示。
