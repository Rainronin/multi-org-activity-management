# 多组织活动管理系统 · UI 风格演示

当前单侧栏版本已获用户认可，是正式前端必须对照还原的视觉与交互基准。AI 开发前须阅读本说明及相关源码、预览；文件映射、迁移和验收要求统一见[前端 UI 设计与规范](../项目文档/前端UI设计与规范.md#前端开发必须以当前-demo-为基础)。存量 CSS 尚未全部 token 化，迁移时须按规范处理；此目录不是业务前端工程或可直接照搬的生产模板。示例组织、人物、活动和数量均为虚构；有登录界面和 AI 文稿交互样例，没有真实登录鉴权、后端请求、数据库或模型调用。刷新页面会清除本次新增的演示草稿。

采用现有前端技术选型中的 Vue 3、TypeScript、Vite、Element Plus 和配套图标。具体版本锁定在 `package-lock.json`。按此次用户要求引入 GSAP，用于卡片错峰入场、数字过渡、折线描绘和环图展开；基础状态使用 CSS。图表使用 SVG，没有安装图表库、Vue Bits、Pinia 或 Vue Router。

## 查看与运行

安装 Node.js 22.12+ 或 24 LTS，在本目录执行：

```powershell
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173>。停止服务按 Ctrl+C。端口被占用时不会自动换端口，先关闭本演示已有服务或手动指定其他端口。

```powershell
npm run build
npm run preview
```

`build` 先进行严格类型检查，再生成 `dist/`；`preview` 用于查看构建结果。此演示采用浏览器模块，请通过本地服务查看，不能双击 `index.html` 运行。

## 可以体验

- 首屏重点活动卡与 AI 文稿卡并列，KPI 缩为下方的信息带，图表与明细继续向下展开。
- 切换可搜索的组织选择器，观察灰色骨架屏及当前组织的数据；右上角“演示选项”可重播加载。骨架等待 850ms 仅用于展示，正式实现应由请求状态驱动。
- 左侧为单个深色悬浮侧栏，展开显示图标、文字和子菜单，折叠后同一栏变为图标岛；仅保留一处品牌和账号入口；组织选择、状态筛选和演示操作分别使用不同形式的选择器／菜单。
- 点击四张 KPI 卡定位到进行中活动、报名明细、本人任务或经费明细。
- 切换近 7／30 天报名批准走势，悬停、点击或通过键盘聚焦数据点查看数值。
- 查看经费环图，再切换活动／报名／经费明细核对数据；不同组织独立汇总。
- 搜索活动、按状态筛选，查看无结果时的呈现。
- 点击活动名称或箭头，展开详情，切换概览与任务清单；Esc 可关闭抽屉。
- 查看“我的任务”，返回对应活动的任务清单。
- 创建简单演示草稿，体验失焦校验与提交兜底校验；不代表正式创建流程。
- 打开 AI 总结或方案编辑：核对关联活动 → 模拟生成 → 采用 → 手动编辑 → 保存演示草稿；也可体验生成失败。总结仅关联复盘中活动，方案仅关联草稿活动。重新生成不自动覆盖编辑，采用新稿覆盖已有文字前确认。编辑内容保留在当前页面内并按活动和文稿类型隔离，刷新清除。
- 右上角“演示选项”或侧栏底部账号菜单可打开左右分屏登录；也可直接访问 <http://127.0.0.1:5173/?view=login>。预填的 demo / demo2026 仅验证表单，不发送或保存凭据。
- 缩窄窗口查看手机布局。表格在自己的区域内横向滚动，页面整体不会横向溢出。

## 设计与文件边界

白色卡片与浅灰背景建立分区，近黑文字建立层级。亮橙 `#FF6B2C` 用于装饰强调，主要按钮采用更深的橙色。保留既有中文系统字体与等宽数字；增加轻边框、小圆角和克制阴影。信息顺序为深色重点活动与暖橙 AI 文稿卡 → 精简 KPI → 图表 → 明细。玻璃效果用半透明、边缘高光、渐变与 backdrop-filter 实现，表格正文保持近不透明底色，未采用扭曲文字的真实折射滤镜；不支持模糊时退化为实色。卡片在精确指针悬停时上浮 4px，减少动效偏好下取消。

图表数据截止 2026-09-12。`demo.ts` 的每日批准汇总样例关联活动 ID，三十天累计与活动的已批准人数一致；不将批准人次解释为实际到场或成员活跃度。经费仅合计已立项活动，排除草稿与待确认；环图表示已确认支出占预算，剩余部分只是预算减已确认支出，不代表账户余额。趋势展示属于此次 UI 探索，尚未增加正式业务开发清单的统计接口。

GSAP 使用 [matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/) 管理减少动态效果偏好及清理。组织变更、组件卸载时撤销旧动画；仅切换趋势范围时只重绘折线，不重复播放整组卡片入场。数字动画不改变供辅助技术读取的准确数值，启用减少动效后直接显示最终状态。

- `src/App.vue`：单栏折叠导航、加载状态、活动列表、详情抽屉与本地草稿状态。
- `src/FocusBoard.vue`：重点活动与关联单场活动的 AI 文稿交互；生成等待 1100ms 和失败均为显式模拟。
- `src/LoginPreview.vue`：左右分屏品牌与登录表单，失焦校验优先；仅演示。
- `src/Overview.vue`：本演示专用的 KPI、趋势、经费图表及其 GSAP 生命周期；不抽象成通用图表平台。
- `src/demo.ts`：带类型的虚构活动及每日批准汇总数据。
- `src/style.css`：视觉变量、响应式排版及减少动态效果支持。
- `smoke.mjs`：最小浏览器回归检查；仅用于开发验证。

保持少量文件便于风格迭代，不提前建立业务模块、共享组件层、接口层和权限系统。正式业务实现仍遵守[前端架构](../项目文档/前端架构与技术栈设计.md)，按实际功能进入 `frontend/`，不能直接将此处的本地数据处理当成业务逻辑。

## 检查

先启动本地演示服务，再执行：

```powershell
npm run check:ui
```

检查使用本机已安装的 Chrome；也可用 `CHROME_PATH` 指定可执行文件、`DEMO_URL` 指定服务地址。覆盖 KPI、每日批准汇总与经费比例、图表明细联动、原有列表与表单、组织切换、刷新重置、手机溢出、悬停微交互、GSAP 收尾、减少动效、分级导航、骨架屏、AI 失败保留文字与登录失焦校验。通过 `SCREENSHOT_DIR` 可指定截图输出目录。检查不验证任何后端业务能力。

前端 UI 规范现已制定；后续页面使用集中 token 与主题映射。本演示检查仅证明原型交互，不证明正式 UI 门禁或业务验收通过。

本轮侧栏改动使用 `src/tokens.css`（与 UI 规范 token 代码块一致）和 `src/sidebar.css`；删除双栏专用旧样式。其余历史页面样式仍按既有原型边界逐步迁移。新增[折叠预览](预览/侧栏折叠.png)，当前[首屏预览](预览/工作台首屏.png)反映合并后的导航。
